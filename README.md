# Bank Loan Analysis Dashboard

This project analyzes loan application data to understand loan approval status, customer profiles, loan amounts, and overall loan performance.

The dashboard was created using **Microsoft Power BI** with data cleaning, analysis, DAX, and interactive visualizations.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Analysis

## 📌 Key Analysis

* Loan Application Analysis
* Approved and Rejected Loans
* Loan Amount Analysis
* Customer Profile Analysis
* Credit Score Analysis
* Loan Performance 

## 🎯 Objective

The objective of this project is to analyze loan data and create an interactive Power BI dashboard that provides insights into loan applications, customer profiles, and approval performance.
